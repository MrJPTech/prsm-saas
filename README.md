## 🎯 What It Is

PRSM SaaS is the unified storefront for everything PRSMTECH sells — Google Workspace APIs, SaaS apps, AI agents, Python CLIs, white-label templates, and bundled packages — all in one place.

The design is intentionally brutalist and industrial: orange `#FF3D00` and cyan `#00B8D4`, hard edges, motion. Every product has a dedicated page; alongside the catalog there's an ROI calculator, a business-assessment quiz, and a booking flow that captures qualified leads into a Supabase backend.

Remotion video compositions are embedded directly in the React tree, so the marketing motion lives in the same codebase as the rest of the surface.
